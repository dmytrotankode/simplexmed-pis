## Сделано на сервере (backend) — готово

- Таблица Приложения 1: генератор `tools/build_annex1.py` переписан — 373 строки (было 365, часть с обрывками описаний),
  тест `tests/test_annex1.py` проверяет, что каждая ошибка даёт своё сообщение; `errors.py` — сопоставление только по
  методу, самое конкретное совпадение, ограниченные шаблоны (без ReDoS), контакты поддержки по умолчанию.
- **Мобильный вход (уязвимость):** код ЕСОЗ больше не уходит в приложение. Сервер сам обменивает код на `/ehealth/return/app`
  и открывает приложение с одноразовым `handle`, который забирается `POST /api/auth/mobile/redeem` только с `code_verifier`.
  Старый обмен `/api/auth/token` с `platform=MOBILE` отклоняется.
- Собственные учётные записи (телефон/пароль) выключены по умолчанию (`PIS_LOCAL_ACCOUNTS`, п.1.5.2 ТВ).
- Удаление учётной записи: `DELETE /api/account` `{"confirm":"DELETE"}` (требование App Store 5.1.1(v) и Google Play).
- IP клиента: доверяем `CF-Connecting-IP` только от сетей Cloudflare (PreProd за Cloudflare); лимит входа по
  нормализованному телефону; отдельный ключ для подписи state; PBKDF2 600k; одинаковое время ответа для неизвестного логина.
- `GET /api/ehealth/person` не отдаёт общий статус верификации (п.3.9.3.8); тексты верификации с абзацами ТВ.
- Подпись запроса на изменение данных — только поля из примера спецификации (иначе 422 на PreProd).
- Справочники по реальному PreProd: причины деклараций — `DECLARATION_REASONS` (а `DECLARATION_STATUS_REASON` на PreProd
  пустой!), статусы — `DECLARATION_STATUSES`; документы дееспособности по умолчанию (`PIS_LEGAL_CAPACITY_DOCUMENT_TYPES`);
  `preferred_way_communication` принимается в любом регистре, в ЕСОЗ уходит `email|phone`.
- Ссылка поддержки НСЗУ: `https://support.ehealth.gov.ua/issues/new`. Адреса без сырых кодов (`STREET` → «вул.»).
- `/api/config`: `local_accounts`, `legal_capacity_document_types`; отсутствующие файлы — 404 (не страница кабинета).
- Локальный стенд `pis/tools/sandbox` (поддельная ЕСОЗ по apib, вход КЕП с паролем `test`, панель сбоев `/__sandbox`).
