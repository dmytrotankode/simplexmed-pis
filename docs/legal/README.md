## Як вводити нову редакцію

1. Створити файли з новою датою у назві (старі не змінювати й не видаляти).
2. Додати запис у таблицю `consent_document` (тип, версія, дата, хеш тексту).
3. Нова редакція обов'язкового документа блокує кабінет екраном згоди до прийняття.
4. Текст віддається BFF як `text/plain`; користувач може зберегти його у `.txt` (ТВ 3.3.1.1).
